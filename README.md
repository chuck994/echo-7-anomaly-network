# ECHO-7 — Anomaly Intelligence Archive

A source-led public research archive for UAP reports, anomalous events, witness testimony, and claims of non-human intelligence.

**Live site:** https://chuck994.github.io/echo-7-anomaly-network/

## Research principles

ECHO-7 distinguishes documented events from interpretations. An official confirmation that a video is authentic does not, by itself, establish what the object depicts or where it came from. Sworn testimony documents what a witness said; it does not automatically prove every underlying allegation. “Unidentified” is not synonymous with “extraterrestrial.”

Records should preserve source links, provenance, uncertainty, credible counterevidence, and the difference between firsthand observation and secondhand reporting.

## Data and contribution

- Curated records: `data/records.json`
- Record schema: `data/record.schema.json`
- Database guide: `DATABASE.md`
- Contribution and sourcing standards: `CONTRIBUTING.md`

This is a curated starter index, not a complete catalog. Records added in the website's browser interface are stored locally in that browser; they are not published to GitHub or shared with other visitors. ECHO-7 is a static GitHub Pages site and does not currently provide automated AI verification, a live global sensor feed, or a shared submission backend.
